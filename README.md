# 💱 Currency Converter Web App

A simple and interactive currency converter web application that allows users to convert any amount from one currency to another in real-time using the latest exchange rates API.

---

## 🚀 Features

- 🌍 Convert between major world currencies
- 🔄 Swap currencies quickly with one click
- 📡 Live exchange rates using API
- 🎯 Simple and user-friendly UI
- ⚡ Fast and lightweight JavaScript calculations

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|---------|
| HTML5     | Structure |
| CSS3      | Styling |
| JavaScript (ES6+) | Functionality & API Integration |
| Exchange Rate API | Fetch Live Real-Time Rates |

---

## 📌 How to Use

1. Select the **From Currency**
2. Select the **To Currency**
3. Enter the **Amount**
4. Click **Convert**
5. Result will be shown instantly ✅
